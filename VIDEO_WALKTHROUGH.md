## Decision to discuss

The interface keeps the stage purpose and prospect-language examples visible beside the caller's outcome control. That supports a quick glance during a live conversation. The prompts are phrased as ways in, not mandatory lines, because a caller needs room to listen and adapt. The transcript set repeatedly shows questions about the caller's purpose, company, and source of the number; it also shows callbacks, requested reports, wrong-person corrections, and clear refusals. Explain one of these patterns in your own words, and how the interface responds to it.

- Set the browser zoom and window size so the active stage, webcam, and call controls are easy to see.
- Use a call from the supplied transcript pack. Keep the transcript file itself out of the repository and use only what you need to demonstrate the product.
